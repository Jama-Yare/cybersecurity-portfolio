# Wazuh SIEM Home Lab

## 1. Project Overview

This project documents my hands-on experience setting up and troubleshooting a Wazuh security monitoring environment using Windows, Kali Linux, and virtualization.

The goal is to learn how security monitoring works, how endpoints communicate with a SIEM platform, and how security events can be investigated.

## 2. Objectives

- Understand the purpose of a Security Information and Event Management (SIEM) system.
- Learn about Wazuh agents and managers.
- Practice endpoint monitoring.
- Troubleshoot Linux services and virtual network connectivity.
- Document security events and investigation findings.

## 3. Tools and Technologies

- Wazuh
- Windows
- Kali Linux
- VirtualBox
- Linux command line
- Windows PowerShell

## 4. Lab Environment

The laboratory uses a Windows host and a Kali Linux virtual machine.

The setup and connectivity requirements are documented as the lab develops.

## 5. Implementation and Troubleshooting

This section will document the actual installation and configuration steps, including:

- Virtual machine configuration.
- Network adapter configuration.
- Wazuh agent installation.
- Service status checks.
- Agent-to-manager connectivity.
- Security event collection and investigation.

## 6. Evidence

Screenshots and sanitized command outputs will be added as the implementation progresses.

## 7. Findings

Findings will be recorded after testing confirms the expected behavior of the environment.

## 8. Lessons Learned

This project is helping me develop practical skills in SIEM administration, Linux troubleshooting, endpoint monitoring, and security documentation.

## 9. Security and Ethics
